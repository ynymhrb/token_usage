# 输入分析报告整体修订跟踪

## 范围

本轮按已确认的输入优化目标修订报告：统一正文 Token 估算与工具细分口径，清理重复类别和内部字段说明，按实际热点生成建议，省略无数据的独立章节，避免图表被套入代码块。

不在本轮伪造历史请求快照、重复次数或节省量。累计用量与正文大小分别呈现，不能相除得到虚假的覆盖率。

## 任务状态

- 已审视：分类表、工具关联与去重、请求样本、建议生成、图表输出及技能转发链路。
- 已编码：统一 Token 细分及去重；合并类别；精简报告；数据驱动建议；图表转发约束。
- 已本地验证：父子表总量一致、重复返回/不同版本返回、同义类别合并、空数据和非工具热点建议；真实日志两表工具结果均为 157,455 Token。已有请求比较测试继续覆盖多会话独立计数及同批请求比较。
- 已安装并验证：0.1.40 安装版 MCP 以“分析今天会话”返回报告，耗时 4.99 秒，父子表均为 159,946 Token（新增日志后数值变化）；两张图均只有一层围栏。164 项测试通过。
- 未实机验收：聊天端模型是否遵循图表原样转发约束。

## 统计与呈现边界

工具结果细分是输入正文表的子表，按同一分词器估算，不乘以未经记录的重复次数。没有请求样本时，用一句话说明不能累计分类用量；有样本时保留单独的累计比较及样本分类，不能混进正文子表。

去重在收集工具正文与细分计数之前共同执行；相同返回不重复计，不同正文版本分别计入。工具分类仍是调用依据推断，不能分配混合返回中的各内层字数。

本轮没有实现历史上下文重放或新请求采集，不宣称正文优化对象就是累计输入消耗排行。建议仅用于选择优先检查的正文，不承诺节省量。
