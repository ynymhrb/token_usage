# 自动查询官方账户用量

## 范围

每次 MCP 分析成功后，通过本地官方 `codex app-server --stdio` 查询账户额度。当前会话范围同时查询该会话的官方估算积分/金额；时间范围和全部历史查询账户活动汇总，不以当前会话费用代替多会话总费用。

## 边界

- 仅调用初始化、`account/rateLimits/read` 和 `account/usage/read`；不发送推理、额度重置或邮件请求。
- 使用当前 Codex 登录，不读取或输出认证令牌，不保存账户响应。
- 账户额度是查询时账户共享快照，与本地选择的日期范围不同。
- 空值显示未提供，零值显示零；估算费用不称作实际账单。
- 15 秒查询超时；保留部分成功结果，失败不使本地报告丢失。仅清理本次启动的服务进程。
- `TOKEN_ANALYZER_CODEX` 可指定官方可执行文件；`TOKEN_ANALYZER_ACCOUNT_QUERY=0` 可关闭查询，默认开启。

## 验证跟踪

- 已编码：协议查询、可执行文件发现、报告区段与范围隔离。
- 已本地验证：142 项全量测试通过；安装版 MCP 的当前会话和昨天两种范围均取得真实额度，账户累计活动 Token 可返回。会话估算查询既观察过 null，也观察过接口报错，分别显示未提供和查询失败。
- 尚未验收：桌面斜杠命令完整交互；MCP 协议验证不替代桌面交互验收。
