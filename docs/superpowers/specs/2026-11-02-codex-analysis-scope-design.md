# Codex 分析范围设计

## 目标

让本地 Codex Token 分析器默认只分析当前会话；用户提供明确自然语言范围时，以该范围覆盖默认会话范围；任何无法解析或缺少当前会话标识的情况均拒绝执行，绝不扩大为全历史扫描。

## 行为

- `--session ID` 优先选择指定会话。
- 没有 `--session` 和 `--scope` 时，从 `CODEX_THREAD_ID`、再从 `CODEX_SESSION_ID` 获取当前会话；均缺失则报错。
- `--scope` 支持：`当前会话`、`全部历史`、`今天`、`昨天`、`最近 N 小时`、`YYYY-MM-DD HH:MM 至 YYYY-MM-DD HH:MM`。
- 除 `全部历史` 外，未知或模糊表述返回错误，不能猜测范围。
- 会话筛选仅以 rollout 文件名中包含的会话标识匹配；时间筛选以 rollout 文件名中 ISO 起始时间匹配，并在报告中标记为“rollout 起始时间范围”。
- 所有范围元数据写入报告，控制台默认仅输出紧凑摘要；完整脱敏 JSON 仅在 `--output` 指定时写入。

## 非目标

- 不调用模型，不读取或回显原始正文。
- 不推断订阅额度、美元成本或服务端压缩。
- 不支持“最近一阵子”“前半段”等没有稳定边界的表述。
