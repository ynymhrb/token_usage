# 报告分类与名称优化

## 目标

细分组合调用工具，使用会话名称，并在缺少完整请求时提供已保存内容的分类统计。

## 实现与验证跟踪

- 已编码：静态识别组合调用里的工具名称与命令类型；多类混合保留独立分类，不伪造内部结果比例。
- 已编码：只读加载会话数据库名称，回退本地索引、数据库标题和报告内未命名序号；不把首条消息误当作已重命名会话的名称。超长名称截断展示。
- 已编码：分类已保存消息、指令、显式 Skill/AGENTS 区块、工具参数及结果。
- 已验证：本地分词词表 SHA-256 与已安装官方分词库内置校验值一致，部署到 `D:/ai_soft/tokenUsage/o200k_base.tiktoken`。不可用时明确显示字符公式粗估，分析阶段不联网。
- 已本地验证：最终名称优先级修正后，136 项全量测试通过；`0.1.24` 安装缓存脚本与源码一致，其 MCP 返回本机工具细分、本地分词器的八类正文统计和重命名后的会话名称。
- 已部署：`0.1.23` 缓存被占用导致覆盖安装失败，改用新的 `0.1.24` 缓存目录安装成功，未终止当前会话。
- 尚未验收：桌面斜杠命令完整交互；协议调用验证不替代桌面交互验收。

## 口径

保存内容每条计一次，并不重建每次模型请求，也不代表当前上下文窗口存量。时间筛选可能排除早先记录的静态指令。会话同名时不合并统计。只读分析不生成报告文件。
