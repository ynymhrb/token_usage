# 累计上下文估算与重复携带

已保存正文分类增加 Token 合计。另增累计对照区，仅从已保存逐次请求累计正文，分别处理每个会话，再汇总。相同工具结果在多个请求中出现时逐次计入。

工具结果由会话、调用标识和正文摘要共同识别，避免不同会话中相同内容或相同调用编号被合并。表格区分出现请求数与重复出现次数，重复次数不含首次。缺少调用标识的结果仍计入正文总量，但不虚构重复关系。

实际输入通过响应标识关联用量记录；对照表只比较可关联的同批请求，实际输入包含缓存输入。样本外的实际输入不混入差值。正文 Token 估算不包含不可见协议等开销，估算与实际的差值不能直接当作可节省量。

未保存逐次请求的历史无法恢复真实重复次数。本版本不使用后续调用次数乘以正文大小来冒充实际累计；此时显示保存正文合计，并说明累计对照不可得。没有新增请求采集功能。

验证包含跨会话隔离、重复请求去重、同批实际用量关联和无样本时不生成虚假数值。
