# Codex 上下文优化插件设计

## 目标

将现有用量诊断器扩展为可安装的 Codex 插件：对插件自身提供的命令执行与文件读取工具，在结果进入模型上下文前进行确定性压缩、重复结果引用和本地留存，从而降低无效上下文占用；在压缩前生成短摘要以保留已完成工作的关键事实。

## 已确认约束

- 不修改 Codex 二进制、网络请求或原生 `Bash`/文件工具。
- Codex 的 `PostToolUse` 当前不能隐藏或替换原生工具输出，因此仅靠钩子无法压缩原生输出；插件必须提供受控 MCP 工具作为压缩边界。
- 默认本地运行、默认不上传；完整原始结果只写入 `PLUGIN_DATA`，模型只收到压缩文本与可追溯标签。
- 压缩失败、输入无法解析、结果较小或命令失败时，保守保留原结果（受硬上限保护），不得伪造摘要。

## 结构

1. `context_optimizer` 负责文本预算、重复指纹、错误行优先、头尾保留与本地收据。
2. 本地 MCP 服务公开 `run_command` 与 `read_file`：执行后先经优化器，再返回模型可见的短结果；完整结果使用哈希标签写入插件数据目录。
3. 插件清单注册 MCP 服务和 `PreCompact`/`PostCompact` 钩子。钩子只注入短会话摘要与统计，不声称能替换原生工具输出。
4. 技能指示代理：大输出命令和文件读取优先使用插件工具；不适用时回退原生工具并记录为不可控路径。

## 安全与验收

- 模型可见结果硬上限默认为 4,000 字符；命令错误保留错误行及头尾证据。
- 相同结果第二次只返回“与先前结果相同”的标签、长度和可选路径标签，不重复注入正文。
- 完整文本不得出现在报告、收据、异常或测试快照中。
- 测试覆盖：小结果原样返回、大结果压缩、错误优先、重复去重、二进制/读取失败降级、Windows 命令参数与钩子输入。

## 非目标

本版本不声称能够压缩任意 Codex 原生工具输出；该能力没有公开的替换接口。它通过受控工具路径实现实际压缩，并明确标注未受控调用。
